# 前端开发工程师岗位要求梳理

## 一、岗位职责（Job Responsibilities）

1. 负责公司 Web 前端项目的**设计与开发**，搭建**高可维护、高性能**的前端工程化框架。
2. 根据业务需求进行**页面实现、交互优化**，并完成 **PC / H5 跨端适配**。
3. 深入参与产品需求讨论，提供**前端可行性方案**，推动前后端高效协作。
4. 在 **PHP + 前端混合模式**的环境下进行业务开发，优化现有架构，提升**渲染性能与用户体验**。
5. 负责前端 **SEO 相关策略**的落地与持续优化（如结构化数据、性能指标优化等）。
6. 持续关注前端前沿技术，主动推动团队在**工程化与性能优化**方面的提升。

---

## 二、任职要求（Qualifications）

### 1. 基础能力与通用素质
- 学习能力强，能够**快速理解业务并独立解决问题**。
- 具备良好的代码规范意识与团队协作习惯。
- 熟悉 Git 工作流，能够进行高效的版本管理与协作开发。

### 2. 前端基础技术
- 精通：
  - HTML5  
  - CSS3  
  - JavaScript  
  - jQuery  
- 熟悉主流前端框架：
  - Vue
  - React

### 3. SEO 与渲染相关能力
- 熟悉 **SEO 原理及落地方案**，包括但不限于：
  - SSR（服务端渲染）
  - Prerender（预渲染）
  - 结构化内容 / 结构化数据
- 能结合性能优化提升搜索引擎友好度。

### 4. 混合渲染与后端协作
- 熟悉 **PHP + 前端混合模式**开发：
  - Smarty / Blade 等模板引擎
  - 传统 MVC 架构
  - 混合渲染方案
- 能在现有系统与架构下**快速上手并优化**。

### 5. Node.js 与工程化
- 熟悉 Node.js，能够：
  - 编写构建 / 辅助脚本
  - 配置和维护工程化工具链
- 熟悉常见构建工具：
  - Webpack
  - Vite
  - Rollup

### 6. 工程化与性能优化经验
- 具备实际工程经验，包括但不限于：
  - 工程化搭建
  - 项目目录规划
  - 组件体系设计
  - 构建与打包优化
  - 前端性能优化

### 7. 后端基础认知
- 掌握基础后端知识，能够：
  - 参与简单接口开发
  - 接口调试
  - 性能调优与问题定位

---

## 三、核心技术关键词（面试高频）

- 前端工程化
- Web 性能优化
- SEO / SSR / Prerender
- Vue / React
- PHP + 前端混合渲染
- Node.js
- Webpack / Vite / Rollup
- 跨端适配（PC / H5）
- 组件化 / 架构优化
