## 🎯 项目概述

**仓库**：be-link-components

**包含**：
- @be-link/antd - PC端组件（基于Ant Design 5.x）
- @be-link/antd-mobile - 移动端组件（基于Ant Design Mobile 5.x）

**技术栈**：
- Node 18+ + pnpm 8+
- Nx 19.x + Lerna 8.x + Rollup 4.x

## ⚙️ 根配置

### package.json

```json
{
  "name": "@be-link/components-monorepo",
  "private": true,
  "engines": {
    "node": ">=18.0.0",
    "pnpm": ">=8.0.0"
  },
  "scripts": {
    "build": "nx run-many -t build",
    "graph": "nx graph",
    "version": "lerna version --conventional-commits",
    "publish": "lerna publish from-package"
  }
}
```

### pnpm-workspace.yaml

```yaml
packages:
  - 'packages/*'
  - 'apps/*'
```

## 🚀 工作流

| 命令 | 说明 |
|------|------|
| `nx build @be-link/antd` | 构建PC组件 |
| `nx affected -t build` | 增量构建 |
| `nx graph` | 查看依赖图 |
| `pnpm version` | 升级版本 |
| `pnpm publish` | 发布 |
