
## 🎯 目标

统一管理项目配置，避免硬编码，实现：

- ✅ 配置与代码分离
- ✅ 多环境配置（开发/测试/生产）
- ✅ TypeScript类型安全
- ✅ 团队协作友好

---

## 📦 依赖说明

### Vite项目（本项目）

**✅ 无需安装额外包**

Vite内置支持`.env`文件：

- 自动加载`.env`、`.env.local`、`.env.[mode]`等文件
- 自动注入以`VITE_`开头的环境变量到`import.meta.env`
- 使用`--mode`参数切换环境，无需 `cross-env` 包
- 无需配置，开箱即用

**工作原理**：

```bash
# 启动开发环境
pnpm dev
# → Vite自动加载 .env + .env.development + .env.local

# 启动测试环境
pnpm dev --mode test
# → Vite自动加载 .env + .env.test + .env.local

# 构建生产环境
pnpm build
# → Vite自动加载 .env + .env.production
```

**⚠️ 关于 cross-env**：

Vite项目**通常不需要** `cross-env`：

```bash
# ❌ 不推荐：使用cross-env
pnpm add -D cross-env
"scripts": {
  "build:test": "cross-env NODE_ENV=test vite build"
}

# ✅ 推荐：使用Vite的--mode参数
"scripts": {
  "build:test": "vite build --mode test"
}
```

**为什么不需要**：

- Vite的`--mode`参数跨平台，Windows/Mac/Linux都能用
- Vite会自动设置`NODE_ENV`（dev时是development，build时是production）
- 更简洁，不需要额外依赖

**极少数需要cross-env的场景**：

```bash
# 如果你的脚本中需要设置其他自定义环境变量
# 且这些变量不在.env文件中
"scripts": {
  "special": "cross-env CUSTOM_VAR=value node script.js"
}
# 但这种情况很少见，通常应该放在.env文件中
```

### 非Vite项目（参考）

如果你的项目使用其他构建工具或Node.js：

**Webpack项目**：

```bash
pnpm add -D dotenv-webpack
pnpm add -D cross-env  # 推荐安装，解决跨平台问题
```

**Node.js项目**：

```bash
pnpm add -D dotenv
pnpm add -D cross-env  # 推荐安装
```

**Create React App**：

- 内置支持，无需额外包
- 使用`REACT_APP_`前缀而非`VITE_`
- 不需要cross-env

## 🏷️ 命名规范

### 环境变量命名

**格式**: `VITE_<分类>_<具体配置>`

**分类建议**：

- `VITE_APP_*` - 应用基础信息
- `VITE_API_*` - API相关配置
- `VITE_<服务名>_*` - 第三方服务（如 VITE_MAP_KEY）
- `VITE_ENABLE_*` - 功能开关

**命名规则**：

- ✅ 必须以 `VITE_` 开头（Vite要求）
- ✅ 全大写，用下划线分隔
- ✅ 语义化，见名知意
- ❌ 避免缩写，除非是通用缩写（如API、URL）

**示例**：

```bash
# ✅ 推荐
VITE_API_BASE_URL=https://api.example.com
VITE_API_TIMEOUT=10000
VITE_MAP_KEY=your-map-key
VITE_ENABLE_MOCK=true

# ❌ 不推荐
VITE_URL=https://api.example.com           # 不明确
VITE_TIMEOUT=10000                         # 缺少分类
VITE_mk=your-key                          # 使用缩写
vite_api_url=https://api.example.com      # 小写
```

### 2. TypeScript类型定义

#### `src/types/env.d.ts`

```typescript
/// <reference types="vite/client" />

/**
 * 环境变量类型定义
 * 
 * 说明：
 * 1. 每次添加新的环境变量，必须在这里添加类型定义
 * 2. 环境变量的值都是string类型
 * 3. boolean类型的配置使用 'true' | 'false'
 */
interface ImportMetaEnv {
  // ========================================
  // 应用基础信息
  // ========================================
  
  /** 应用名称 */
  readonly VITE_APP_NAME: string
  
  /** 应用版本号 */
  readonly VITE_APP_VERSION: string
  
  // ========================================
  // API配置
  // ========================================
  
  /** API基础地址 */
  readonly VITE_API_BASE_URL: string
  
  /** API请求超时时间(ms) */
  readonly VITE_API_TIMEOUT: string
  
  // ========================================
  // 第三方服务配置
  // ========================================
  
  /** 地图服务Key */
  readonly VITE_MAP_KEY: string
  
  // ========================================
  // CDN配置
  // ========================================
  
  /** CDN基础地址 */
  readonly VITE_CDN_URL: string
  
  // ========================================
  // 功能开关
  // ========================================
  
  /** 是否启用Mock数据 */
  readonly VITE_ENABLE_MOCK: 'true' | 'false'
  
  /** 是否启用VConsole调试工具 */
  readonly VITE_ENABLE_VCONSOLE: 'true' | 'false'
  
  /** 是否生成SourceMap */
  readonly VITE_BUILD_SOURCEMAP: 'true' | 'false'
}

interface ImportMeta {
  readonly env: ImportMetaEnv
}
```

### 3. 环境配置工具类

#### `src/config/env.ts`

```typescript
/**
 * 环境配置工具类
 * 
 * 使用方式：
 * import { env } from '@/config/env'
 * 
 * const apiUrl = env.apiBaseUrl
 * if (env.isDev) {
 *   console.log('开发环境')
 * }
 */
class EnvConfig {
  // ========================================
  // 应用基础信息
  // ========================================
  
  /** 应用名称 */
  get appName(): string {
    return import.meta.env.VITE_APP_NAME
  }

  /** 应用版本 */
  get appVersion(): string {
    return import.meta.env.VITE_APP_VERSION
  }

  // ========================================
  // 环境判断
  // ========================================
  
  /** 是否开发环境 */
  get isDev(): boolean {
    return import.meta.env.DEV
  }

  /** 是否生产环境 */
  get isProd(): boolean {
    return import.meta.env.PROD
  }

  /** 是否测试环境 */
  get isTest(): boolean {
    return import.meta.env.MODE === 'test'
  }

  // ========================================
  // API配置
  // ========================================
  
  /** API基础地址 */
  get apiBaseUrl(): string {
    return import.meta.env.VITE_API_BASE_URL
  }

  /** API超时时间(ms) */
  get apiTimeout(): number {
    return this.toNumber(import.meta.env.VITE_API_TIMEOUT, 10000)
  }

  // ========================================
  // 第三方服务配置
  // ========================================
  
  /** 地图服务Key */
  get mapKey(): string {
    return import.meta.env.VITE_MAP_KEY
  }

  // ========================================
  // CDN配置
  // ========================================
  
  /** CDN基础地址 */
  get cdnUrl(): string {
    return import.meta.env.VITE_CDN_URL
  }

  // ========================================
  // 功能开关
  // ========================================
  
  /** 是否启用Mock */
  get enableMock(): boolean {
    return this.toBoolean(import.meta.env.VITE_ENABLE_MOCK)
  }

  /** 是否启用VConsole */
  get enableVConsole(): boolean {
    return this.toBoolean(import.meta.env.VITE_ENABLE_VCONSOLE)
  }

  /** 是否生成SourceMap */
  get buildSourceMap(): boolean {
    return this.toBoolean(import.meta.env.VITE_BUILD_SOURCEMAP)
  }

  // ========================================
  // 私有工具方法
  // ========================================
  
  /**
   * 字符串转boolean
   * @private
   */
  private toBoolean(value: string | undefined): boolean {
    return value === 'true'
  }

  /**
   * 字符串转number
   * @private
   */
  private toNumber(value: string | undefined, defaultValue: number = 0): number {
    const num = Number(value)
    return isNaN(num) ? defaultValue : num
  }

  // ========================================
  // 公共方法
  // ========================================
  
  /**
   * 验证必需的环境变量
   * 在应用启动时调用
   */
  validate(): void {
    const required: Array<keyof ImportMetaEnv> = [
      'VITE_APP_NAME',
      'VITE_API_BASE_URL',
      // 在这里添加其他必需的环境变量
    ]

    const missing = required.filter(key => !import.meta.env[key])

    if (missing.length > 0) {
      const errorMsg = `❌ 缺少必需的环境变量: ${missing.join(', ')}`
      console.error(errorMsg)
      throw new Error(errorMsg)
    }
  }

  /**
   * 打印当前配置（仅开发环境）
   */
  printConfig(): void {
    if (!this.isDev) return

    console.group('🔧 环境配置')
    console.log('环境:', import.meta.env.MODE)
    console.log('应用:', this.appName)
    console.log('版本:', this.appVersion)
    console.log('API:', this.apiBaseUrl)
    console.log('Mock:', this.enableMock)
    console.log('VConsole:', this.enableVConsole)
    console.groupEnd()
  }
}

// 导出单例
export const env = new EnvConfig()

// 应用启动时验证和打印配置
if (import.meta.env.MODE !== 'test') {
  env.validate()
  env.printConfig()
}
```

## ⚠️ 注意事项

### 0. Vite环境变量工作原理

**加载时机**：

- 环境变量在**构建时**被静态替换到代码中
- 不是运行时动态读取

**加载规则**：

```bash
# 开发环境 (pnpm dev)
加载顺序：
1. .env                     # 所有情况都会加载
2. .env.local               # 所有情况都会加载，会被git忽略
3. .env.development         # 只在开发模式加载
4. .env.development.local   # 只在开发模式加载，会被git忽略

# 生产环境 (pnpm build)
加载顺序：
1. .env
2. .env.local
3. .env.production
4. .env.production.local

# 优先级：后加载的会覆盖先加载的
```

**前缀限制**：

- ✅ `VITE_` 开头的变量会暴露给客户端代码
- ❌ 其他变量（如`API_SECRET`）不会暴露，保护敏感信息

**示例**：

```bash
# .env
VITE_API_URL=https://api.example.com  # ✅ 客户端可访问
DATABASE_URL=postgres://xxx           # ❌ 客户端不可访问（安全）
```

```typescript
// 在代码中
console.log(import.meta.env.VITE_API_URL)     // ✅ 正常输出
console.log(import.meta.env.DATABASE_URL)     // ❌ undefined
```

### 1. 安全性

**✅ 可以提交到Git**：

- `.env`、`.env.development`、`.env.test`、`.env.production`
- 使用占位符（如 `your-key-here`）

**❌ 不能提交到Git**：

- `.env.local`、`.env.*.local`
- 包含真实密钥的文件

### 2. 类型转换

环境变量的值都是字符串，需要转换：

```typescript
// ❌ 错误用法
if (import.meta.env.VITE_ENABLE_MOCK) {  // 永远是true（字符串）
  // ...
}

// ✅ 正确用法
if (env.enableMock) {  // 工具类已转换为boolean
  // ...
}
```

### 3. 必须重启

修改 `.env.*` 文件后，**必须重启** `pnpm dev`：

```bash
# 1. 停止开发服务器 (Ctrl+C)
# 2. 重新启动
pnpm dev
```

### 4. 使用规范

**✅ 推荐**：

```typescript
import { env } from '@/config/env'
const apiUrl = env.apiBaseUrl  // 有类型提示、有转换
```

**❌ 不推荐**：

```typescript
const apiUrl = import.meta.env.VITE_API_BASE_URL  // 容易拼错、没有转换
```

## 🆘 常见问题

### Q0: Vite项目需要安装dotenv或cross-env吗？

**A**: 都不需要！

**关于 dotenv**：

```bash
# ❌ 不需要这些包
pnpm add dotenv
pnpm add dotenv-webpack

# ✅ Vite内置支持，无需额外安装
```

**关于 cross-env**：

```bash
# ❌ 不推荐
pnpm add -D cross-env
"dev:test": "cross-env NODE_ENV=test vite"

# ✅ 推荐：使用Vite的--mode参数
"dev:test": "vite --mode test"
```

**为什么不需要cross-env**：

- Vite的`--mode`参数本身就是跨平台的
- 自动处理Windows和Unix系统的差异
- 更简洁，更符合Vite的设计理念

**对比**：

```bash
# 传统方式（需要cross-env）
"build:test": "cross-env NODE_ENV=test webpack build"

# Vite方式（不需要cross-env）
"build:test": "vite build --mode test"
```

**其他项目**：

- Webpack项目：通常需要 `cross-env`
- 纯Node.js项目：通常需要 `cross-env`
- Vite项目：**不需要**

### Q1: 为什么要用工具类而不是直接访问？

**A**:

- ✅ IDE自动补全，避免拼写错误
- ✅ 类型安全，编译时检查
- ✅ 自动转换类型（string → boolean/number）
- ✅ 统一管理，便于维护

### Q2: 如何在CI/CD中配置环境变量？

**A**:

```yaml
# GitHub Actions
- name: Build
  run: pnpm build
  env:
    VITE_MAP_KEY: ${{ secrets.MAP_KEY }}

# GitLab CI
build:
  script: pnpm build
  variables:
    VITE_MAP_KEY: $MAP_KEY
```

### Q3: 本地配置被覆盖了怎么办？

**A**: 环境变量加载优先级（从高到低）：

```
.env.production.local   # 最高
.env.production
.env.local
.env                    # 最低
```

创建 `.env.local` 或 `.env.development.local` 可以覆盖默认配置。

### Q4: 环境变量不生效怎么办？

**A**: 按顺序检查：

1. **检查前缀**：

```bash
# ❌ 错误：没有VITE_前缀
API_URL=https://xxx

# ✅ 正确
VITE_API_URL=https://xxx
```

2. **重启开发服务器**：

```bash
# 修改.env文件后必须重启
# Ctrl+C 停止
pnpm dev  # 重新启动
```

3. **检查文件位置**：

```
✅ 正确位置：
项目根目录/.env
项目根目录/.env.development

❌ 错误位置：
src/.env
public/.env
```

4. **检查文件名**：

```bash
# ✅ 正确
.env
.env.development

# ❌ 错误
env
.env.dev  # 应该是 .env.development
```
