# 个人知识库

个人技术知识库与工作空间。

## 目录结构

```
xuan-hub/
├── knowledge/          # 技术知识库
│   ├── frontend/       # 前端开发
│   │   ├── basics/     # HTML、CSS、JavaScript 基础
│   │   ├── browser/    # 浏览器原理与 DevTools
│   │   ├── frameworks/ # React、Vue 等框架
│   │   ├── engineering/# 构建工具、包管理、微前端
│   │   ├── libraries/  # MobX、WebSocket、Node、Webpack
│   │   └── solutions/  # 技术解决方案
│   └── backend/        # 后端知识（Nginx 等）
├── work/               # 工作相关
│   ├── projects/       # 项目文档
│   ├── team/           # 团队规范与标准
│   └── xuanshan/       # 玄山项目
├── tools/              # 工具使用指南
│   └── cursor/         # Cursor IDE 配置
├── demos/              # 示例项目
│   ├── memory-leak-react/
│   └── websocket-react/
├── personal/           # 个人内容
│   ├── life/           # 生活待办
│   └── career/         # 职业发展
└── resources/          # 资源文件
    ├── templates/      # 文档模板
    └── attachments/    # 附件
```
