## 回滚方案

### 触发条件

出现以下情况时执行回滚：
- 服务无法启动
- 数据异常
- 性能严重下降

### 回滚步骤

```bash
# 1. 停止服务
pnpm run stop

# 2. 恢复备份
cp config.json.bak config.json

# 3. 重启服务
pnpm run start
```

### 回滚验证

```bash
# 确认服务恢复正常
curl http://localhost:3000/health
```

## 常见问题

### Q1: 出现权限错误

**现象**：`Permission denied`

**解决**：
```bash
sudo chown -R $USER:$USER ./
```

### Q2: 端口被占用

**现象**：`Port 3000 is already in use`

**解决**：
```bash
# 查找占用进程
lsof -i :3000

# 终止进程
kill -9 <PID>
```
