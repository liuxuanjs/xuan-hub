# 知识库写作规范速查卡

## 文档类型选择

```
概念/术语/命令 → 知识卡（≤500字）
技术方案/问题分析 → 专题文（500-2000字）
部署/操作流程 → 操作手册（1000-3000字）
```

## 元数据模板

```yaml
---
aliases: ["别名1", "别名2"]
title: "文章标题"
tags: ["技术栈", "场景"]
updated: 2026-01-09
---
```

## 结构速查

### 知识卡
```
定义 → 核心要点(3-5条) → 示例代码 → 速查命令 → 相关链接
```

### 专题文
```
概述(问题/方案/结论) → 背景 → 核心概念表格 → 实现步骤 → 故障排查表 → 最佳实践 → 参考
```

### 操作手册
```
概览(目标/时长/风险/前提) → 执行清单 → 前置准备 → 分阶段步骤 → 验证检查表 → 回滚方案
```

## 写作禁忌

| ❌ 禁止 | ✅ 改为 |
|--------|--------|
| "大家好" | 直接开始正文 |
| "本文将介绍" | 用"概述"章节 |
| "总结一下" | 用"要点总结"表格 |
| "接下来我们来看" | 直接写内容 |
| 长段落 | 列表/表格 |

## 标识符号

```markdown
✅ 推荐做法
❌ 禁止做法
⚠️ 注意事项
🔧 工具推荐
```

