# 知识库文章模板

本目录包含知识库文章的标准模板，确保新增文章遵循统一规范。

## 模板列表

| 模板 | 字数要求 | 适用场景 | 触发词 |
|------|----------|----------|--------|
| [[知识卡模板]] | ≤500 | 概念定义、命令速查、术语解释 | "整理 X 知识卡" |
| [[专题文模板]] | 500-2000 | 技术选型、问题排查、系统实践 | "写 X 专题文档" |
| [[操作手册模板]] | 1000-3000 | 部署流程、故障预案、项目搭建 | "制作 X 操作手册" |
| [[写作规范速查卡]] | — | 写作时快速参考 | — |

## 使用方式

### 1. 选择模板

根据内容类型选择对应模板：

- **知识卡**：单一概念、快速查阅
- **专题文**：深入分析、方案对比
- **操作手册**：步骤指引、可执行

### 2. 复制模板

```bash
# 创建新的知识卡
cp resources/templates/知识卡模板.md knowledge/frontend/basics/xxx/新文章.md

# 创建新的专题文
cp resources/templates/专题文模板.md knowledge/frontend/solutions/新方案.md

# 创建新的操作手册
cp resources/templates/操作手册模板.md knowledge/backend/部署手册.md
```

### 3. 填充内容

1. 更新元数据（aliases、title、tags、updated）
2. 按模板结构填写内容
3. 删除不需要的可选章节
4. 确保代码可直接运行

## 写作规范速查

### 元数据格式

```yaml
---
aliases: ["别名1", "别名2"]
title: "文章标题"
tags: ["技术栈", "场景"]
updated: 2026-01-09
---
```

### 核心原则

- ✅ **先结论后论证**：开篇即给出核心观点
- ✅ **列表优先**：用列表代替长段落
- ✅ **表格对比**：方案对比必用表格
- ❌ **禁止博客口吻**："大家好"、"本文将"、"总结一下"
- ❌ **禁止空洞铺垫**：直接进入主题

### 结构化标识

```markdown
✅ 推荐做法
❌ 禁止做法
⚠️ 注意事项
🔧 工具推荐
```

### 代码规范

- 使用正确的语法高亮：`javascript`、`bash`、`css`、`html`
- 命令注释用 `#`
- 标注前置条件（版本、依赖）
- 确保代码可直接复制运行
