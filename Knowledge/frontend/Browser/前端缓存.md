## 概览

**目的**：减少请求、加速加载、降低服务器压力

**核心策略**：
- HTML：不缓存或协商缓存
- 静态资源（JS/CSS/图片）：强缓存 + 文件名哈希
- API 数据：按需设置短期缓存

## 缓存类型

### 强缓存（不发请求）

浏览器直接使用本地缓存，不与服务器通信。

**控制方式**：`Cache-Control` 响应头

```http
# 缓存一年（静态资源）
Cache-Control: public, max-age=31536000

# 不缓存（HTML）
Cache-Control: no-cache, no-store, must-revalidate

# 私有缓存（用户数据）
Cache-Control: private, max-age=300
```

| 指令 | 含义 |
|------|------|
| `max-age=秒数` | 缓存有效期 |
| `public` | 可被 CDN 等中间节点缓存 |
| `private` | 只能被浏览器缓存 |
| `no-cache` | 每次需要向服务器验证 |
| `no-store` | 完全不缓存 |
| `immutable` | 资源永不变化 |

### 协商缓存（需要请求确认）

浏览器向服务器确认资源是否更新，未更新则返回 304。

**方式一：ETag（推荐）**

```http
# 服务器响应
ETag: "abc123"

# 浏览器下次请求
If-None-Match: "abc123"
```

**方式二：Last-Modified**

```http
# 服务器响应
Last-Modified: Wed, 21 Oct 2024 07:28:00 GMT

# 浏览器下次请求
If-Modified-Since: Wed, 21 Oct 2024 07:28:00 GMT
```

## 缓存流程图

```
浏览器请求资源
    ↓
有本地缓存？ ─否→ 请求服务器 → 返回200 + 数据
    ↓是
缓存过期？ ─否→ 使用缓存（from cache）
    ↓是
发送验证请求（带 ETag/Last-Modified）
    ↓
资源变了？ ─否→ 返回304 → 使用本地缓存
    ↓是
返回200 + 新数据 → 更新缓存
```

## 最佳实践

### 不同资源的缓存策略

| 资源类型 | 缓存策略 | Cache-Control |
|---------|---------|---------------|
| HTML | 不缓存/协商缓存 | `no-cache` |
| JS/CSS（带 hash） | 强缓存一年 | `max-age=31536000, immutable` |
| 图片/字体（带 hash） | 强缓存一年 | `max-age=31536000` |
| API 数据 | 短期或不缓存 | `private, max-age=60` |

### 文件名哈希

```javascript
// Webpack 配置
output: {
  filename: '[name].[contenthash:8].js',
  chunkFilename: '[name].[contenthash:8].chunk.js'
}
```

**原理**：文件内容变化 → 哈希值变化 → 文件名变化 → 浏览器请求新文件

### Nginx 配置示例

```nginx
# 静态资源长缓存
location ~* \.(js|css|png|jpg|gif|ico|svg|woff2)$ {
    expires 1y;
    add_header Cache-Control "public, immutable";
}

# HTML 不缓存
location ~* \.html$ {
    add_header Cache-Control "no-cache, no-store, must-revalidate";
}
```

## Service Worker 缓存

适用于 PWA 应用，可编程控制缓存策略。

```javascript
// 注册 Service Worker
navigator.serviceWorker.register('/sw.js');

// sw.js - 缓存优先策略
self.addEventListener('fetch', event => {
  event.respondWith(
    caches.match(event.request).then(cached => {
      return cached || fetch(event.request);
    })
  );
});
```

## 常见问题

### 问题1：用户看到旧版本

**原因**：HTML 被缓存了

**解决**：HTML 设置 `Cache-Control: no-cache`

### 问题2：更新后缓存不生效

**原因**：文件名没变，浏览器使用旧缓存

**解决**：使用文件名哈希（contenthash）

### 问题3：CDN 缓存未更新

**原因**：CDN 边缘节点缓存未刷新

**解决**：CDN 控制台刷新缓存，或使用版本号

## 调试方法

**DevTools Network 面板**：

| 状态 | 含义 |
|------|------|
| `(from disk cache)` | 强缓存命中（磁盘） |
| `(from memory cache)` | 强缓存命中（内存） |
| `304 Not Modified` | 协商缓存命中 |
| `200` | 新请求或缓存失效 |

**强制刷新**：
- `Ctrl/Cmd + Shift + R`：跳过缓存刷新
- DevTools 勾选 `Disable cache`：禁用缓存
