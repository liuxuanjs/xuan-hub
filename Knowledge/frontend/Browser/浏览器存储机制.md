## 核心对比

| 特性 | Cookie | localStorage | sessionStorage | IndexedDB |
|------|--------|--------------|----------------|-----------|
| **容量** | 4KB | 5-10MB | 5-10MB | 无限制 |
| **生命周期** | 可设置过期时间 | 永久（手动清除） | 页面关闭清除 | 永久 |
| **作用域** | 同源 + 路径 | 同源 | 同源 + 同标签页 | 同源 |
| **随请求发送** | ✅ 自动携带 | ❌ | ❌ | ❌ |
| **API** | document.cookie | 简单 KV | 简单 KV | 异步复杂 |
| **适用场景** | 身份认证 | 持久化数据 | 临时表单数据 | 大量结构化数据 |

## Cookie

### 基本特性

- **容量**：单个 Cookie 4KB，每个域名 20-50 个
- **自动携带**：每次 HTTP 请求自动发送到服务器
- **主要用途**：身份认证（Session ID、Token）

### 重要属性

| 属性 | 作用 | 示例 |
|------|------|------|
| `expires` / `max-age` | 过期时间 | `max-age=3600`（1小时） |
| `domain` | 可访问的域名 | `domain=.example.com` |
| `path` | 可访问的路径 | `path=/admin` |
| `secure` | 仅 HTTPS 传输 | `secure` |
| `httpOnly` | 禁止 JS 访问 | `httpOnly`（防 XSS） |
| `sameSite` | 跨站限制 | `Strict` / `Lax` / `None` |

### SameSite 详解

| 值 | 行为 | 适用场景 |
|----|------|---------|
| `Strict` | 完全禁止跨站携带 | 敏感操作（转账） |
| `Lax` | 允许导航跨站携带（默认） | 一般场景 |
| `None` | 允许跨站携带（需 Secure） | 第三方服务 |

### 操作方式

```javascript
// 设置 Cookie
document.cookie = 'name=value; max-age=3600; path=/; secure; samesite=lax';

// 读取 Cookie（需解析）
function getCookie(name) {
  const match = document.cookie.match(new RegExp(`(^| )${name}=([^;]+)`));
  return match ? match[2] : null;
}

// 删除 Cookie（设置过期）
document.cookie = 'name=; max-age=0';

// 推荐：使用 js-cookie 库
import Cookies from 'js-cookie';
Cookies.set('name', 'value', { expires: 7 });
Cookies.get('name');
Cookies.remove('name');
```

### 服务端设置

```http
Set-Cookie: sessionId=abc123; Max-Age=3600; HttpOnly; Secure; SameSite=Strict
```

## localStorage

### 基本特性

- **容量**：5-10MB
- **生命周期**：永久存储，除非手动清除
- **作用域**：同源共享（协议 + 域名 + 端口）

### API

```javascript
// 存储
localStorage.setItem('user', JSON.stringify({ name: 'test', id: 1 }));

// 读取
const user = JSON.parse(localStorage.getItem('user'));

// 删除
localStorage.removeItem('user');

// 清空
localStorage.clear();

// 遍历
for (let i = 0; i < localStorage.length; i++) {
  const key = localStorage.key(i);
  console.log(key, localStorage.getItem(key));
}
```

### 监听变化（跨标签页通信）

```javascript
// 其他同源标签页修改 localStorage 时触发
window.addEventListener('storage', (e) => {
  console.log('key:', e.key);
  console.log('oldValue:', e.oldValue);
  console.log('newValue:', e.newValue);
  console.log('url:', e.url);
});
```

### 适用场景

- 用户偏好设置（主题、语言）
- 不敏感的持久化数据
- 缓存 API 响应数据

## sessionStorage

### 与 localStorage 的区别

| 对比项 | localStorage | sessionStorage |
|--------|--------------|----------------|
| 生命周期 | 永久 | 页面会话结束清除 |
| 标签页共享 | 同源共享 | 仅当前标签页 |
| 新标签页 | 可访问 | 独立存储 |

### API

与 localStorage 完全相同：

```javascript
sessionStorage.setItem('key', 'value');
sessionStorage.getItem('key');
sessionStorage.removeItem('key');
sessionStorage.clear();
```

### 适用场景

- 表单数据临时保存（防刷新丢失）
- 单次会话的状态数据
- 页面间传递数据（同标签页）

## IndexedDB

### 基本特性

- **容量**：几乎无限制（通常为磁盘空间的 50%）
- **存储类型**：支持结构化数据、文件、Blob
- **API 特点**：异步操作，基于事务

### 基本使用

```javascript
// 打开/创建数据库
const request = indexedDB.open('myDB', 1);

// 数据库升级（创建表结构）
request.onupgradeneeded = (e) => {
  const db = e.target.result;

  // 创建对象仓库（类似表）
  const store = db.createObjectStore('users', { keyPath: 'id', autoIncrement: true });

  // 创建索引
  store.createIndex('name', 'name', { unique: false });
  store.createIndex('email', 'email', { unique: true });
};

// 数据库打开成功
request.onsuccess = (e) => {
  const db = e.target.result;

  // 添加数据
  const tx = db.transaction('users', 'readwrite');
  const store = tx.objectStore('users');
  store.add({ name: 'John', email: 'john@example.com' });

  // 查询数据
  const getRequest = store.get(1);
  getRequest.onsuccess = () => {
    console.log(getRequest.result);
  };
};
```

### 推荐：使用封装库

原生 API 繁琐，推荐使用 `idb` 或 `Dexie.js`：

```javascript
// 使用 idb 库（Promise 封装）
import { openDB } from 'idb';

const db = await openDB('myDB', 1, {
  upgrade(db) {
    db.createObjectStore('users', { keyPath: 'id' });
  }
});

// 添加
await db.add('users', { id: 1, name: 'John' });

// 查询
const user = await db.get('users', 1);

// 遍历
const allUsers = await db.getAll('users');
```

### 适用场景

- 大量数据离线存储
- 复杂查询需求
- PWA 离线应用
- 文件/Blob 存储

## 存储方案选择

```
需要服务端读取？
    │
    ├── 是 → Cookie（注意 HttpOnly）
    │
    └── 否 → 数据量大吗？
              │
              ├── 大（>5MB）→ IndexedDB
              │
              └── 小 → 需要持久化吗？
                        │
                        ├── 是 → localStorage
                        │
                        └── 否 → sessionStorage
```

## 常见面试题

### Q1：Cookie、localStorage、sessionStorage 的区别？

| 维度 | Cookie | localStorage | sessionStorage |
|------|--------|--------------|----------------|
| 容量 | 4KB | 5-10MB | 5-10MB |
| 服务端访问 | ✅ 自动携带 | ❌ | ❌ |
| 生命周期 | 可设置 | 永久 | 会话结束 |
| 标签页共享 | ✅ | ✅ | ❌ |

### Q2：如何实现跨标签页通信？

1. **localStorage + storage 事件**
2. **BroadcastChannel API**
3. **SharedWorker**
4. **postMessage（需要窗口引用）**

```javascript
// 方案1：localStorage
localStorage.setItem('message', JSON.stringify({ type: 'update', data: {} }));

// 方案2：BroadcastChannel
const channel = new BroadcastChannel('my-channel');
channel.postMessage({ type: 'update' });
channel.onmessage = (e) => console.log(e.data);
```

### Q3：Cookie 如何防止 XSS 攻击读取？

设置 `HttpOnly` 属性，禁止 JavaScript 通过 `document.cookie` 访问。

### Q4：第三方 Cookie 是什么？有什么问题？

- **定义**：非当前页面域名设置的 Cookie（如广告追踪）
- **问题**：隐私问题，用于跨站追踪用户
- **趋势**：浏览器逐步限制（Safari/Firefox 已默认阻止，Chrome 采用 Privacy Sandbox 替代方案）

### Q5：localStorage 满了怎么办？

```javascript
try {
  localStorage.setItem('key', 'value');
} catch (e) {
  if (e.name === 'QuotaExceededError') {
    // 清理旧数据或使用 IndexedDB
    localStorage.clear();
  }
}
```
