## 结论

小程序 + WebView H5 + iframe 的三层架构，通信路径如下：

```
┌─────────────────────────────────────────────────────────────┐
│                        小程序                                │
│  page/web-view/index                                        │
│  • wx.miniProgram.navigateTo (实时)                         │
│  • onMessage 接收 H5 消息 (非实时)                           │
└────────────────────────────┬────────────────────────────────┘
                             │ WebView
                             ↓
┌─────────────────────────────────────────────────────────────┐
│                     H5 父页面                                │
│  authDomain/scene                                           │
│  • window.addEventListener('message') 监听 iframe           │
│  • wx.miniProgram.postMessage 发给小程序                     │
│  • wx.miniProgram.navigateTo 跳转小程序                      │
└────────────────────────────┬────────────────────────────────┘
                             │ iframe
                             ↓
┌─────────────────────────────────────────────────────────────┐
│                      iframe 业务页                           │
│  liveDomain/scene-main                                      │
│  • window.parent.postMessage 发给父页面                      │
│  • window.addEventListener('message') 监听父页面             │
└─────────────────────────────────────────────────────────────┘
```

## 通信方式对比

| 方向 | 方法 | 实时性 | 用途 |
|------|------|--------|------|
| iframe → 父页面 | `window.parent.postMessage` | 实时 | 支付、分享、关闭弹窗 |
| 父页面 → iframe | `iframe.contentWindow.postMessage` | 实时 | 重置路由 |
| H5 → 小程序 | `wx.miniProgram.postMessage` | **非实时** | 分享信息 |
| H5 → 小程序 | `wx.miniProgram.navigateTo` | 实时 | 支付、授权 |
| 小程序 → H5 | URL 参数 | 初始化时 | 用户信息、token |

## 消息类型定义

统一管理所有消息类型，避免混乱：

```typescript
enum IFRAME_MESSAGE_TYPE {
  IFRAME_READY = 'IFRAME_READY',           // iframe 加载完成
  LIVE_READY_SHARE = 'LIVE_READY_SHARE',   // 分享信息就绪
  PULL_PAY_PAGE = 'PULL_PAY_PAGE',         // 拉起支付
  CLOSE_LIVE_IFRAME_POPUP = 'CLOSE_LIVE_IFRAME_POPUP',  // 关闭弹窗
  RESET_IFRAME_ROUTE = 'RESET_IFRAME_ROUTE',  // 重置路由
}

// 类型安全的消息定义
type IframeMessageParams =
  | { type: IFRAME_MESSAGE_TYPE.IFRAME_READY }
  | { type: IFRAME_MESSAGE_TYPE.LIVE_READY_SHARE; shareConfig: IframeShareConfig }
  | { type: IFRAME_MESSAGE_TYPE.PULL_PAY_PAGE; payParam: IRequestPayment }
  | { type: IFRAME_MESSAGE_TYPE.CLOSE_LIVE_IFRAME_POPUP }
  | { type: IFRAME_MESSAGE_TYPE.RESET_IFRAME_ROUTE; path: string };
```

## 场景1：支付

iframe 里点击购买 → 小程序支付页。

### 通信链路

```
iframe 商品页
  │
  │ window.parent.postMessage({ type: 'PULL_PAY_PAGE', payParam })
  ↓
H5 父页面监听到消息
  │
  │ wx.miniProgram.navigateTo({ url: '/page/payment-result/index?payParams=...' })
  ↓
小程序支付页
  │
  │ Taro.requestPayment()
  ↓
支付完成，navigateBack 返回 WebView
```

### 代码实现

**iframe 内发送：**

```typescript
// 判断是否在 iframe 中
const isIframePopup = window.parent !== window;

const pullPayPage = (payParam: IRequestPayment) => {
  if (isIframePopup) {
    // 在 iframe 中，发消息给父页面
    window.parent.postMessage({
      type: IFRAME_MESSAGE_TYPE.PULL_PAY_PAGE,
      payParam,
    }, '*');
  } else {
    // 不在 iframe 中，直接跳转
    wx.miniProgram.navigateTo({
      url: `/page/payment-result/index?payParams=${encodeURIComponent(JSON.stringify(payParam))}`,
    });
  }
};
```

**父页面监听：**

```typescript
// hooks: usePullPayPageListener
useEffect(() => {
  const handleMessage = (event: MessageEvent) => {
    if (event.data?.type === IFRAME_MESSAGE_TYPE.PULL_PAY_PAGE) {
      wx.miniProgram.navigateTo({
        url: `/page/payment-result/index?payParams=${encodeURIComponent(JSON.stringify(event.data.payParam))}`,
      });
    }
  };
  window.addEventListener('message', handleMessage);
  return () => window.removeEventListener('message', handleMessage);
}, []);
```

## 场景2：分享

iframe 直播间 → 小程序分享。

### 通信链路

```
iframe 直播间页面初始化
  │
  │ window.parent.postMessage({ type: 'LIVE_READY_SHARE', shareConfig })
  ↓
H5 父页面监听到消息
  │
  │ wx.miniProgram.postMessage({ data: { type: 'share', data: shareConfig } })
  ↓
（等待用户触发分享）
  ↓
小程序 onMessage 收到消息
  │
  │ 更新 shareInfoRef
  ↓
用户点击分享
  │
  │ useShareAppMessage 返回 shareInfoRef.current
  ↓
分享成功
```

### 为什么这么复杂

因为 `wx.miniProgram.postMessage` **不是实时的**，只在用户触发分享时才能收到。

所以要**提前发送**分享信息，让小程序缓存好，等用户点分享时直接用。

### 代码实现

**iframe 内发送：**

```typescript
// 页面加载完成后，发送分享信息
useEffect(() => {
  const shareConfig = {
    title: `${storeName} - ${liveName}`,
    path: `page/index/index?pageKey=LIVE&activityId=${activityId}`,
    imageUrl: coverImage,
  };
  window.parent.postMessage({
    type: IFRAME_MESSAGE_TYPE.LIVE_READY_SHARE,
    shareConfig,
  }, '*');
}, []);
```

**父页面转发：**

```typescript
// hooks: useLiveReadyShareListener
useEffect(() => {
  const handleMessage = (event: MessageEvent) => {
    if (event.data?.type === IFRAME_MESSAGE_TYPE.LIVE_READY_SHARE) {
      wx.miniProgram.postMessage({
        data: { type: 'share', data: event.data.shareConfig },
      });
    }
  };
  window.addEventListener('message', handleMessage);
  return () => window.removeEventListener('message', handleMessage);
}, []);
```

**小程序接收：**

```typescript
// page/web-view/index.tsx
const shareInfoRef = useRef({ title: '', path: '', imageUrl: '' });

const onWebViewMessage = (e) => {
  const messages = e.detail.data || [];
  const lastMessage = messages[messages.length - 1];

  if (lastMessage?.type === 'share') {
    shareInfoRef.current = lastMessage.data;
  }
};

useShareAppMessage(() => shareInfoRef.current);

return <WebView src={url} onMessage={onWebViewMessage} />;
```

## 场景3：重置 iframe 路由

父页面打开弹窗 → 重置 iframe 内的路由。

### 问题背景

iframe 可能被浏览器缓存。关闭弹窗再打开时，iframe 还停留在上次的路由状态。

### 通信链路

```
父页面打开弹窗
  │
  │ iframeRef.current.contentWindow.postMessage({ type: 'RESET_IFRAME_ROUTE', path })
  ↓
iframe 监听到消息
  │
  │ navigate(path, { replace: true })
  ↓
iframe 路由重置成功
```

### 代码实现

**父页面发送：**

```typescript
const resetIframeRoute = (iframeElement: HTMLIFrameElement | null, path: string) => {
  if (iframeElement?.contentWindow) {
    iframeElement.contentWindow.postMessage({
      type: IFRAME_MESSAGE_TYPE.RESET_IFRAME_ROUTE,
      path,
    }, '*');
  }
};

// 打开弹窗时调用
const openPopup = (path: string) => {
  setPopupVisible(true);
  resetIframeRoute(iframeRef.current, path);
};
```

**iframe 内监听：**

```typescript
// hooks: useIframeRouteResetListener
const useIframeRouteResetListener = (onReset: (path: string) => void) => {
  useEffect(() => {
    const handleMessage = (event: MessageEvent) => {
      if (event.data?.type === IFRAME_MESSAGE_TYPE.RESET_IFRAME_ROUTE) {
        onReset(event.data.path);
      }
    };
    window.addEventListener('message', handleMessage);
    return () => window.removeEventListener('message', handleMessage);
  }, [onReset]);
};

// 使用
const navigate = useNavigate();
useIframeRouteResetListener((path) => {
  navigate(path, { replace: true });
});
```

## 场景4：关闭弹窗

iframe 内点击关闭 → 通知父页面关闭弹窗。

### 代码实现

**iframe 内发送：**

```typescript
const closeLiveIframePopup = () => {
  window.parent.postMessage({
    type: IFRAME_MESSAGE_TYPE.CLOSE_LIVE_IFRAME_POPUP,
  }, '*');
};

// 点击关闭按钮
<Button onClick={closeLiveIframePopup}>关闭</Button>
```

**父页面监听：**

```typescript
const useCloseLiveIframePopupListener = (close: () => void) => {
  useEffect(() => {
    const handleMessage = (event: MessageEvent) => {
      if (event.data?.type === IFRAME_MESSAGE_TYPE.CLOSE_LIVE_IFRAME_POPUP) {
        close();
      }
    };
    window.addEventListener('message', handleMessage);
    return () => window.removeEventListener('message', handleMessage);
  }, [close]);
};

// 使用
useCloseLiveIframePopupListener(() => setPopupVisible(false));
```

## 多层嵌套处理

如果 iframe 里还嵌套了 iframe（多层），需要找到顶层窗口：

```typescript
const getTopWindow = () => {
  let win: Window = window;
  while (win.parent !== win) {
    win = win.parent;
  }
  return win;
};

// 发消息给顶层
getTopWindow().postMessage(message, '*');
```

## 安全考虑

### 生产环境指定 origin

开发时图方便用 `'*'`，生产环境要指定具体域名：

```typescript
// 发送时
window.parent.postMessage(message, 'https://your-domain.com');

// 接收时校验
window.addEventListener('message', (event) => {
  if (event.origin !== 'https://allowed-domain.com') {
    return;  // 忽略不信任来源
  }
  // 处理消息
});
```

### 消息类型校验

不要信任任何消息内容，做好类型检查：

```typescript
const handleMessage = (event: MessageEvent) => {
  const { type, data } = event.data || {};

  // 校验消息类型
  if (!Object.values(IFRAME_MESSAGE_TYPE).includes(type)) {
    return;
  }

  // 根据类型处理
  switch (type) {
    case IFRAME_MESSAGE_TYPE.PULL_PAY_PAGE:
      if (isValidPayParam(data)) {
        handlePay(data);
      }
      break;
    // ...
  }
};
```
