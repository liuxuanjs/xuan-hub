## 结论

小程序 + WebView H5 架构下，有三种授权方式：

| 授权方式 | 触发场景 | 用户感知 | 获取信息 |
|----------|----------|----------|----------|
| 小程序静默登录 | 入口页自动触发 | 无感知 | openId、unionId |
| H5 微信网页授权 | 需要头像昵称时 | 跳转授权页 | 头像、昵称、unionId |
| 手机号授权 | 下单前 | 点击按钮授权 | 手机号 |

三种授权各司其职，按需触发。

## 小程序静默登录

用户打开小程序，自动完成登录，无需任何操作。

### 流程

```
用户打开小程序
     ↓
入口页调用 Taro.login() 获取 code
     ↓
用 code 请求后端 /user/login
     ↓
后端用 code 换 openId、unionId
     ↓
后端返回 token + 用户信息
     ↓
前端保存 token，登录完成
```

### 实现

```typescript
// store/useAuthStore.ts
const getUserInfoByCode = async () => {
  // 1. 获取微信 code
  const { code } = await Taro.login();

  // 2. 用 code 换用户信息
  const res = await fetchUserLogin({
    jsCode: code,
    appId: Taro.getAccountInfoSync().miniProgram.appId,
  });

  // 3. 保存登录态
  beLinkHttp.setToken(res.data.token);
  return res.data.userInfo;
};
```

### 这一步能获取什么

| 信息 | 是否能获取 |
|------|-----------|
| openId | 是 |
| unionId | 是（需关联公众号） |
| 头像 | 否 |
| 昵称 | 否 |
| 手机号 | 否 |

**静默登录只能拿到标识，不能拿到用户资料。**

## H5 微信网页授权

WebView 里的 H5 需要用户头像、昵称时，要走微信网页授权。

### 为什么需要

小程序把 openId、unionId 传给 H5，H5 可以登录。但如果业务需要显示用户头像、昵称，就需要网页授权。

### 流程

```
H5 判断需要授权
     ↓
跳转微信授权页（用户看到授权弹窗）
     ↓
用户同意，微信回调带 code
     ↓
H5 用 code 请求后端换用户信息
     ↓
获取到头像、昵称、unionId
```

### 授权页实现

```typescript
// pages/auth/index.tsx
const Auth: React.FC = () => {
  const code = searchParams.get('code');
  const unionId = searchParams.get('unionId');
  const needWxAuth = searchParams.get('needWxAuth') === 'true';

  useEffect(() => {
    // 判断是否需要网页授权
    const shouldAuth = !code && (needWxAuth || !unionId);

    if (shouldAuth) {
      // 跳转微信授权页
      weixinAuth.authorize(window.location.href, 'snsapi_userinfo');
    } else {
      // 已有 code 或不需要授权，执行登录
      authenticate().then((userData) => {
        // 跳转到目标页面
        window.location.replace(targetUrl);
      });
    }
  }, []);

  return <Loading text='正在授权...' />;
};
```

### 授权 URL 构造

```typescript
// utils/weixin/auth.ts
class WeixinAuth {
  buildAuthUrl(redirectUri: string, scope: WeixinAuthScope): string {
    return `https://open.weixin.qq.com/connect/oauth2/authorize?` +
      `appid=${this.wechatMpAppId}` +
      `&redirect_uri=${encodeURIComponent(redirectUri)}` +
      `&response_type=code` +
      `&scope=${scope}` +
      `#wechat_redirect`;
  }

  authorize(redirectUri: string, scope: WeixinAuthScope): void {
    window.location.replace(this.buildAuthUrl(redirectUri, scope));
  }
}
```

### 两种授权范围

| scope | 用户体验 | 获取信息 |
|-------|---------|----------|
| snsapi_base | 静默，无弹窗 | 只有 openId |
| snsapi_userinfo | 弹窗确认 | openId + 头像 + 昵称 |

### 授权域名配置

网页授权需要在公众号后台配置**网页授权域名**。

公众号后台 → 设置与开发 → 公众号设置 → 功能设置 → 网页授权域名

**限制**：最多 2 个域名。

## 手机号授权

下单时需要手机号，需要用户主动点击按钮授权。

### 为什么放在下单前

- 手机号是敏感信息，微信限制必须用户主动触发
- 不是所有用户都会下单，按需获取减少打扰
- 提高转化率（用户已有下单意愿时更愿意授权）

### 流程

```
用户点击"去结算"
     ↓
H5 检测没有手机号
     ↓
跳转到小程序手机号授权页
     ↓
用户点击"授权手机号登录"
     ↓
微信弹出授权确认
     ↓
用户确认，获取 code
     ↓
用 code 请求后端获取手机号
     ↓
返回上一页，继续下单
```

### 实现

```typescript
// page/phone-auth/index.tsx
export default function PhoneAuth() {
  const handleGetPhoneNumber = async (e) => {
    const { code } = e.detail;

    if (!code) {
      // 用户拒绝
      showToast('已取消授权');
      Taro.navigateBack();
      return;
    }

    // 用 code 换手机号
    const result = await fetchPhoneAuth({
      code,
      userId,
      appId: Taro.getAccountInfoSync().miniProgram.appId,
    });

    if (result.success) {
      showToast('授权成功');
      Taro.navigateBack();
    }
  };

  return (
    <Button
      openType='getPhoneNumber'
      onGetPhoneNumber={handleGetPhoneNumber}
    >
      授权手机号登录
    </Button>
  );
}
```

### 为什么要跳到小程序原生页

`getPhoneNumber` 按钮只能在小程序原生页面使用，WebView 里的 H5 无法调用。

所以流程是：H5 → 跳转小程序原生页 → 授权 → 返回 H5。

## 完整授权链路

把三种授权串起来：

```
用户打开小程序
     ↓
【入口页】静默登录，获取 openId、token
     ↓
跳转到 WebView 加载 H5
     ↓
【H5 授权页】判断是否需要网页授权
     │
     ├─ 需要 → 跳转微信授权 → 获取头像昵称 → 跳转目标页
     │
     └─ 不需要 → 直接跳转目标页
     ↓
用户浏览商品、进入直播间...
     ↓
用户点击"去结算"
     ↓
【H5】检测没有手机号 → 跳转小程序手机号授权页
     ↓
【小程序】用户授权手机号 → 返回 H5
     ↓
【H5】继续下单流程
```

## 登录态传递

小程序和 H5 怎么共享登录态？

### 小程序 → H5

通过 URL 参数传递：

```typescript
// 小程序 WebView 页面
const url = setObjToUrlParams(`${domain}/auth`, {
  unionId,
  openId,
  userId,
  token,
  // ...
});

return <WebView src={url} />;
```

### H5 → 小程序

通过 `wx.miniProgram.navigateTo` 的 URL 参数：

```typescript
// H5 跳转小程序
wx.miniProgram.navigateTo({
  url: `/page/phone-auth/index?userId=${userId}`,
});
```

## 授权拒绝处理

用户可能拒绝授权，要优雅处理。

### 网页授权拒绝

用户在微信授权页点击"拒绝"，会回调到原页面但没有 code。

```typescript
useEffect(() => {
  const handleVisibilityChange = () => {
    const isToAuth = localStorage.getItem('is_to_auth');
    if (isToAuth) {
      // 用户从授权页返回，但没有 code，说明拒绝了
      localStorage.removeItem('is_to_auth');
      wx.miniProgram.redirectTo({ url: '/page/index/index' });
    }
  };

  document.addEventListener('visibilitychange', handleVisibilityChange);
}, []);
```

### 手机号授权拒绝

用户点击"拒绝"，`e.detail.code` 为空。

```typescript
const handleGetPhoneNumber = (e) => {
  if (!e.detail.code) {
    showToast('已取消授权');
    Taro.navigateBack();
    return;
  }
  // 继续处理...
};
```

## 常见问题

### unionId 什么时候有

unionId 需要小程序和公众号**关联到同一个开放平台账号**。

如果没关联，小程序只能拿到 openId，无法和公众号用户打通。

### 网页授权域名不够用

只有 2 个名额。解决方案：
- 用一个代理域名，nginx 转发到各业务域名
- 授权页放在固定域名，授权完成后跳转到业务域名

### H5 刷新后登录态丢失

URL 参数只在第一次访问时有，刷新后可能丢失。

解决方案：
- H5 登录后把 token 存到 localStorage
- 刷新时优先从 localStorage 读取
- localStorage 没有再从 URL 读取

```typescript
// H5 端
const getToken = () => {
  return localStorage.getItem('token') || searchParams.get('token');
};
```

## 经验总结

| 原则 | 做法 |
|------|------|
| 能静默就静默 | 入口页自动完成基础登录 |
| 按需授权 | 需要时再要求用户授权更多信息 |
| 拒绝友好 | 用户拒绝授权不能卡死，给出引导 |
| 登录态共享 | URL 参数 + localStorage 双保险 |
