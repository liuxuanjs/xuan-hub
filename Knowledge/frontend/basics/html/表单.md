## 概述

HTML 表单用于收集用户输入，是 Web 应用与用户交互的核心机制。表单包含各种输入控件：文本字段、复选框、单选按钮、下拉列表等。

## 核心元素

| 元素 | 作用 |
|------|------|
| `<form>` | 定义表单容器 |
| `<input>` | 输入控件（多种类型） |
| `<textarea>` | 多行文本输入 |
| `<select>` | 下拉列表 |
| `<option>` | 下拉选项 |
| `<button>` | 按钮 |
| `<label>` | 标签（关联控件） |

## 表单属性

| 属性 | 作用 | 示例值 |
|------|------|--------|
| `action` | 提交地址 | `/api/submit` |
| `method` | 提交方法 | `get`、`post` |
| `enctype` | 编码类型 | `multipart/form-data` |
| `target` | 提交目标 | `_blank`、`_self` |

## 输入类型

### 常用 input type

| 类型 | 作用 | 示例 |
|------|------|------|
| `text` | 单行文本 | 用户名 |
| `password` | 密码（掩码） | 登录密码 |
| `email` | 邮箱（带验证） | 邮箱地址 |
| `number` | 数字 | 年龄、数量 |
| `tel` | 电话 | 手机号 |
| `date` | 日期选择器 | 生日 |
| `radio` | 单选按钮 | 性别 |
| `checkbox` | 复选框 | 同意条款 |
| `file` | 文件上传 | 头像 |
| `submit` | 提交按钮 | — |

### 完整示例

```html
<form action="/api/register" method="post">
    <!-- 文本输入 -->
    <label for="username">用户名:</label>
    <input type="text" id="username" name="username" required>

    <!-- 密码输入 -->
    <label for="password">密码:</label>
    <input type="password" id="password" name="password" minlength="8">

    <!-- 邮箱输入 -->
    <label for="email">邮箱:</label>
    <input type="email" id="email" name="email">

    <!-- 单选按钮 -->
    <fieldset>
        <legend>性别:</legend>
        <input type="radio" id="male" name="gender" value="male">
        <label for="male">男</label>
        <input type="radio" id="female" name="gender" value="female">
        <label for="female">女</label>
    </fieldset>

    <!-- 复选框 -->
    <input type="checkbox" id="agree" name="agree" required>
    <label for="agree">同意用户协议</label>

    <!-- 提交 -->
    <button type="submit">注册</button>
</form>
```

## 下拉列表

### 单选下拉

```html
<label for="city">城市:</label>
<select id="city" name="city">
    <option value="">请选择</option>
    <option value="beijing">北京</option>
    <option value="shanghai">上海</option>
    <option value="guangzhou">广州</option>
</select>
```

### 多选下拉

```html
<label for="skills">技能（多选）:</label>
<select id="skills" name="skills" multiple>
    <option value="html">HTML</option>
    <option value="css">CSS</option>
    <option value="js">JavaScript</option>
</select>
```

## 表单验证

### HTML5 内置验证属性

| 属性 | 作用 |
|------|------|
| `required` | 必填 |
| `minlength` / `maxlength` | 长度限制 |
| `min` / `max` | 数值范围 |
| `pattern` | 正则匹配 |

```html
<input type="text" name="phone" pattern="1[3-9]\d{9}" title="请输入有效手机号">
```

### JavaScript 验证

```javascript
const form = document.querySelector('form');

form.addEventListener('submit', (e) => {
    e.preventDefault(); // 阻止默认提交

    const formData = new FormData(form);
    // 自定义验证逻辑
    if (validateForm(formData)) {
        form.submit();
    }
});
```

## 常见问题

### 1. 表单编码

| 编码类型 | 适用场景 |
|----------|----------|
| `application/x-www-form-urlencoded` | 默认，普通表单 |
| `multipart/form-data` | 文件上传 |
| `text/plain` | 纯文本 |

```html
<!-- 文件上传必须设置 enctype -->
<form enctype="multipart/form-data">
    <input type="file" name="avatar">
</form>
```

### 2. 安全问题

| 问题 | 防护措施 |
|------|----------|
| **CSRF** | 添加 CSRF Token |
| **XSS** | 转义用户输入 |
| **SQL 注入** | 参数化查询 |

### 3. 可访问性

```html
<!-- 正确：label 关联 input -->
<label for="name">姓名</label>
<input type="text" id="name" name="name">

<!-- 或使用嵌套 -->
<label>
    姓名
    <input type="text" name="name">
</label>
```

### 4. 移动端优化

```html
<!-- 数字键盘 -->
<input type="tel" inputmode="numeric">

<!-- 关闭自动更正 -->
<input type="text" autocorrect="off" autocapitalize="off">
```
