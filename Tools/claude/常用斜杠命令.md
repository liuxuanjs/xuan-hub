# 常用命令

## /init

生成项目配置文档 `CLAUDE.md`。

**什么时候用**：
- 第一次在项目里用 Claude Code
- 项目结构改了

**怎么用**：
```bash
/init
```

会分析项目生成配置文档，包括技术栈、目录结构、常用命令等。

---

## /commit-commands:commit

自动生成 commit 消息并提交。

**怎么用**：
```bash
/commit-commands:commit
# 或者直接说 "帮我提交代码"
```

**做了什么**：
1. 看你改了啥（git diff）
2. 生成 commit 消息（feat/fix/refactor等）
3. git add + git commit

**注意**：
- 提交前看一眼是不是都想提交的文件
- 别一次提交太多不相关的东西

---

## /commit-commands:commit-push-pr

提交 + 推送 + 创建 PR，一步搞定。

**怎么用**：
```bash
/commit-commands:commit-push-pr
```

**前提**：
- 装了 `gh` CLI
- 配置了 GitHub（`gh auth login`）

会自动生成 PR 描述，包括改了啥、测试计划等。

**踩坑**：
- 第一次用可能会提示装 gh，按提示装就行
- 确保当前分支已经关联了远程仓库

## /feature-dev

帮你写功能，会分析项目、设计方案、生成代码。

**怎么用**：
```bash
/feature-dev
```

然后描述你要做什么。

**怎么描述效果好**：

❌ 不好：
```
做一个登录
```

✅ 好：
```
实现用户登录功能

需求：
1. POST /api/login 登录接口
2. 用户名+密码登录
3. 返回 JWT token（7天有效）
4. 密码用 bcrypt 加密

技术栈：Express.js + MongoDB
集成点：src/routes/auth.js
现有代码：User 模型在 src/models/user.js
```

**注意事项**：
- **一次性把需求说完整，别一句一回车**（这个很重要）
- 说清楚技术栈、在哪集成
- 生成的代码不要直接用，要审查

**会做什么**：
1. 读现有代码
2. 设计方案
3. 生成代码文件
4. 集成到项目
5. 生成测试

## /code-review

审查代码，找问题和给建议。

**怎么用**：
```bash
/code-review
```

**会检查啥**：
- 安全问题（XSS、SQL注入等）
- 代码质量（命名、复杂度）
- 性能问题
- 最佳实践

**报告分级**：
- 🔴 严重问题 - 必须改
- 🟡 建议 - 看情况
- 🟢 做得好 - 继续保持

**使用场景**：
- 提交前审查一遍
- feature-dev 生成代码后审查

## /resume

恢复之前的对话会话，继续上次的工作。

**怎么用**：
```bash
# 在 Claude Code 交互界面执行
/resume
```

**作用**：
- 恢复上一次的对话历史
- 继续之前中断的任务
- 保持上下文连续性

**使用场景**：
- Claude Code 关闭后重新打开，想继续之前的工作
- 切换项目后，想回到之前的对话
- 中途退出，后续想接着干

**注意**：
- 只能恢复最近一次的会话
- 如果距离上次会话时间太久，可能需要重新描述需求

## 组合使用

**完整开发流程**：
```bash
/feature-dev      # 开发功能
/code-review      # 审查代码
# 修复问题...
/commit-commands:commit-push-pr   # 提交并创建 PR
```

**快速修 Bug**：
```bash
# 修复...
/code-review      # 审查一下
/commit-commands:commit   # 提交
```

## 常见问题

**Q: /feature-dev 生成的代码能直接用吗？**

不行，要审查：
1. 用 `/code-review` 审查
2. 跑测试
3. 人工检查关键逻辑（尤其是安全、权限相关）

**Q: 需求描述为什么不能一句一回车？**

因为可能会丢信息。最好完整输入后再发送。

**Q: /commit-commands:commit-push-pr 失败了？**

检查：
```bash
gh --version  # 看装了没
gh auth status  # 看登录了没
git remote -v  # 看有没有远程仓库
```
