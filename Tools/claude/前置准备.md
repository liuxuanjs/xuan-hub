# Claude Code 前置准备

## 执行清单

- [ ] 安装 Claude Code CLI 工具
- [ ] 配置 API 环境变量（zshrc）
- [ ] 配置用户级全局指令文件
- [ ] 了解内置技能使用
- [ ] 验证环境配置

---

## 第一步：安装 Claude Code CLI

### 推荐方式：curl（推荐）

必须保证本地 Node 版本大于等于 18，建议 20 以上

```bash
# 使用 curl 安装
curl -fsSL https://claude.ai/install.sh | sh
```

**为什么推荐 curl？**
- ✅ 始终获取最新版本
- ✅ 不影响 pnpm 等包管理器版本
- ✅ 适配 volta/nvm 等 Node 版本管理工具

### 备选方式：npm

```bash
# 如果已有 Node 环境
npm install -g @anthropic-ai/claude-code
```

⚠️ **不推荐 Homebrew**：版本更新滞后，可能与 pnpm 版本冲突

### 验证安装

```bash
# 检查版本
claude --version

# 登录 Claude 账号
claude login
```

**预期输出**：显示版本号并成功完成浏览器授权登录

## 第二步：配置 API 环境变量（可选）

### 作用

配置环境变量用于：
- 使用第三方 Claude API 代理服务（如 88code）
- 自定义 API 端点
- 优化网络流量

### 编辑 ~/.zshrc

```bash
# 打开 zsh 配置文件
open ~/.zshrc
```

### 配置示例

```bash
# Claude API 认证配置
export ANTHROPIC_AUTH_TOKEN=your_api_token_here
export ANTHROPIC_BASE_URL=https://your-api-proxy.com/api

# 禁用非必要流量（可选，提升速度）
export CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC=1
```

### 常用代理服务配置

**88code（示例）**：
```bash
export ANTHROPIC_AUTH_TOKEN=88_your_token_here
export ANTHROPIC_BASE_URL=https://www.88code.ai/api
```

### 使配置生效

```bash
# 重新加载配置
source ~/.zshrc

# 验证环境变量
echo $ANTHROPIC_BASE_URL
```

⚠️ **注意**：
- Token 为敏感信息，切勿提交到 Git 仓库
- 使用官方 API 时可跳过此步骤
- 代理服务的稳定性和安全性需自行评估

## 第三步：配置用户级 CLAUDE.md

### 作用

用户级 `CLAUDE.md` 是全局配置文件，对所有项目生效，用于设置 Claude Code 的默认行为偏好。

### 创建配置文件

```bash
# 安装 Claude Code 后已经有 ~/.claude 目录了，直接编辑配置文件
vi ~/.claude/CLAUDE.md
```

### 推荐配置内容

```markdown
# Always reply in Chinese

# Creating a git commit without any signed endings
```

**配置说明**：
- `Always reply in Chinese`：强制 Claude 使用中文回复
- `Creating a git commit without any signed endings`：生成 Git Commit 时不添加签名后缀

### 配置优先级

```
项目级 CLAUDE.md > 用户级 CLAUDE.md > Claude 默认行为
```

## 故障排查

### 问题 1：`claude: command not found`

**原因**：未添加到 PATH 或安装失败

**解决方案**：
```bash
# 检查安装路径
which claude

# 手动添加到 PATH（如果使用 curl 安装）
export PATH="$HOME/.claude/bin:$PATH"

# 将上述命令添加到 ~/.zshrc 或 ~/.bashrc
echo 'export PATH="$HOME/.claude/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc
```

### 问题 2：CLAUDE.md 未生效

**检查步骤**：
1. 确认文件路径 `~/.claude/CLAUDE.md` 拼写正确
2. 检查文件编码为 UTF-8
3. 重启 Claude Code 会话

### 问题 3：API 代理连接失败

**原因**：环境变量未生效或代理服务不可用

**解决方案**：
```bash
# 检查环境变量是否已设置
env | grep ANTHROPIC

# 验证 API 端点可访问
curl -I $ANTHROPIC_BASE_URL

# 测试 Token 是否有效（如使用 88code）
curl -H "Authorization: Bearer $ANTHROPIC_AUTH_TOKEN" $ANTHROPIC_BASE_URL/health

# 如环境变量未生效，重新加载配置
source ~/.zshrc

# 或重启终端窗口
```

**回退到官方 API**：
```bash
# 临时禁用代理配置
unset ANTHROPIC_AUTH_TOKEN
unset ANTHROPIC_BASE_URL

# 或注释掉 ~/.zshrc 中的相关配置行
```
